# Реєстр приватних сонячних електростанцій (СЕС)

Цей проєкт є виконанням **Практичної роботи №3** з дисципліни "Основи веб-програмування" (Варіант 2: Облік сонячних електростанцій). 

Веб-додаток дозволяє реєструвати приватні СЕС, автоматично розраховувати їхню потужність, зберігати дані на сервері та переглядати загальну статистику.

## Функціонал

* **Реєстрація СЕС:** Збір даних про власника, адресу, тип панелей та їх кількість.
* **Динамічні розрахунки:** Автоматичний підрахунок загальної потужності (кВт) на основі введених даних.
* **Умовні поля:** Динамічна поява поля "Ємність" при виборі наявності акумуляторів.
* **Статистика (Dashboard):** Підрахунок загальної кількості СЕС, їх сумарної потужності та кількості станцій з акумуляторами.
* **Фільтрація:** Можливість фільтрувати збережені записи за типом об'єкта (Будинок, Дача, Бізнес).
* **Серверне збереження:** Дані зберігаються у форматі JSON (`data/ses.json`), імітуючи роботу з базою даних.

## Технології

* **Frontend:** HTML5, CSS3, Vanilla JavaScript (Fetch API).
* **Backend:** Node.js, Express.js.
* **Дані:** JSON (File System module).

## Запуск проєкту локально

Для запуску проєкту на вашому комп'ютері має бути встановлений [Node.js](https://nodejs.org/).

1. Зклонуйте цей репозиторій або завантажте архів з кодом.
2. Відкрийте термінал (командний рядок) у папці проєкту.
3. Встановіть необхідні залежності командою:  
   ```bash
   npm install
   ```  
4.  Запустіть локальний сервер:
    ```bash
    node server.js
    ```
5.  Відкрийте браузер і перейдіть за адресою:
    [http://localhost:3000](http://localhost:3000)

## Структура проєкту

  * `server.js` — головний файл бекенду (налаштування Express та API маршрутів).
  * `public/` — папка зі статичними файлами фронтенду:
      * `index.html` — розмітка сторінки.
      * `style.css` — стилі додатку.
      * `script.js` — клієнтська логіка та взаємодія з API.
  * `data/` — папка для збереження бази даних (`ses.json`).
